# CV32E40P XpulpNN DATE 2020 Implementation Plan

> 本计划已按用户批准的“主代理实施＋独立审查”方式执行。2026-10-21 的最终任务状态见下表；后文保留原始实施步骤，作为验收依据与历史计划，不代表待办清单。

**Goal:** 在当前 CV32E40P 上完整实现 DATE 2020 的4/2位 packed ALU、dot/sdot、双通道 qnt，交付真实指令验证和有证据边界的 FPGA 可行性结果。

**Architecture:** 固定本地原始 RTL，采用同名覆盖文件集成新功能，三个独立 NN 执行块分别负责 ALU、点积和量化。量化通过 LSU 内部专属端口复用 OBI 传输，controller 保持精确的暂停与最终提交；基线和扩展使用同样的存储器、FF RF 和平台时钟门控进行比较。

**Tech Stack:** SystemVerilog；Vivado/XSim 2026.1；xPack RISC-V GCC/binutils 15.2.0；Python 3.12 标准库；PowerShell；Vivado Tcl。

**Spec:** `C:/Users/CEG/FYP/docs/superpowers/specs/2026-10-20-xpulpnn-cv32e40p-design.md`。用户已确认的范围见 `C:/Users/CEG/FYP/docs/investigation/2026-10-20-xpulpnn-feasibility-review-zh.md` 第7节；用户已批准本地 ABI、规格和计划。

## Global Constraints

- 32位 GPR、累加器和总线保持不变。
- 完整保留当前核心已有的 RV32IMC 和 PULP 指令。不得通过重新分配合法的 extract、shuffle、pack、complex 等编码获得新功能。
- 原始 E 盘核心、D 盘旧原型和 `FYP.xpr` 保留；生成可复现的本地扩展源码和独立 Vivado 工程。
- 不声称与原作者未取得的机器码/编译器二进制兼容；以下新增编码与量化布局是本项目明确选择的 ABI。
- 新增参数 `COREV_XPULPNN=0`；启用仅支持 `COREV_PULP=1, COREV_CLUSTER=0, FPU=0, ZFINX=0`。
- 器件固定 `xck26-sfvc784-2LV-c`。首次布局布线时钟固定为10 ns；若不能满足，保留失败结果，可对两组同时尝试20 ns，并分别标明约束。
- 当前 top 没有总线错误输入，核心也关闭 PMP，因此本项目不新增外部访存错误架构。
- 当前项目不是 Git 仓库。用不可变快照、逐文件哈希和差异补丁建立检查点；本计划不初始化仓库、不要求虚构的 commit/worktree。

## Review Focus

1. qnt 基址前一拍来自 load/forwarding：不得依据旧基址提前触发异常；有效和无效基址都必须按真正源值判断。归属 Task 6。
2. 连续 qnt 交替2/4位、两个激活走相反路径：每条操作和每个通道必须独立初始化，最终恰好一次写回。归属 Task 5、6。
3. 普通 LSU 尚有响应、qnt 请求 grant 延迟、最终写回阻塞：不得丢响应、重复请求或污染普通 load 元数据。归属 Task 6、7。
4. 打开或关闭扩展后，旧编码的合法性、第三操作数及看似反直觉的 avg 溢出语义仍一致。归属 Task 2、3、4、7。
5. 运行更少周期不自动代表更短 FPGA 时间；OOC 通过不自动代表板级引脚和硬件运行正确。归属 Task 8、9、10。
