# KV260 Board Validation Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement the tasks and verify each result.

**Goal:** Program the attached XCK26 with the repository processor, collect checked physical results, and publish reproducible sources/evidence.

**Architecture:** Existing CPU/BRAM benchmark system plus a passive signature stream and VIO board adapter. PS PL0 provides the clock; JTAG controls execution and reads captured output.

**Tech Stack:** SystemVerilog, Vivado 2026.1, XSDB, Python, Tcl.

**Spec:** `docs/superpowers/specs/2026-10-29-kv260-board-design.md`

## Constraints and review focus

- Preserve original project and frozen sources; use pinned common ROM for both configurations.
- Check build identity, output count/data/fold, readback overflow, and nonzero counters.
- Restore memory with a fresh bitstream for repeated trials; never report stale output as a run.
- Fail on timing/DRC errors; report actual configured clock and avoid claiming physical frequency measurement.
- Retain failed attempts honestly; publish portable evidence without generated tool trees.
